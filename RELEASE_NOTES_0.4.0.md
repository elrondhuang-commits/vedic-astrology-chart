# Release notes — 0.4.0

## Complete Shodashavarga

This release adds the final five charts in the classical sixteen-chart set:

- D27 Saptavimshamsha
- D30 Trimshamsha
- D40 Khavedamsha
- D45 Akshavedamsha
- D60 Shashtiamsha

The Streamlit selector now exposes all fifteen D-number vargas alongside D1. D40, D45, and D60 show localized warnings about birth-time sensitivity. D60 currently displays chart signs and houses; deity-name metadata is reserved for a later release.

## Tests

The suite verifies equal-division boundaries, D30 unequal spans for odd and even signs, registry completeness, and complete generation of every Shodashavarga chart.
