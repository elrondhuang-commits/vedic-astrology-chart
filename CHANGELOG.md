# Changelog

All notable project changes are recorded here.

## 0.3.0 — 2026-07-28

### Added

- D16 Shodashamsha with modality-based starts: Aries, Leo, Sagittarius.
- D20 Vimshamsha with modality-based starts: Aries, Sagittarius, Leo.
- D24 Chaturvimshamsha using the declared odd-Leo/even-Cancer zodiacal convention.
- Boundary tests for every new varga.
- Full-chart regression test confirming D16, D20, and D24 are generated with ten positions and a first-house Ascendant.

### Changed

- Updated bilingual interface summaries and calculation notes.
- Extended the Varga Registry to ten selectable divisional charts.
- Updated project version to `0.3.0`.

## 0.2.1

- Added the unified Varga Registry.
- Fixed missing D4, D7, and D12 localized descriptions.

## 0.2.0

- Introduced modular `core/`, `charts/`, `tests/`, and `docs/` packages.

## Earlier prototypes

- Added D1, Moon chart, D2, D3, D4, D7, D9, D10, D12, and Vimshottari Mahadasha/Antardasha.
